# Customer Churn Prediction

A machine learning project for predicting customer churn in the telecommunications industry.

## Overview

Customer churn is an important business problem in the telecom industry. This project analyzes customer data and builds machine learning models to predict whether a customer is likely to leave the service.

Three machine learning approaches are compared:

- Artificial Neural Network (ANN)
- Logistic Regression
- Random Forest

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- PyTorch
- Jupyter Notebook

## Project Workflow

1. Data loading
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature preprocessing and scaling
5. Model training
6. Model evaluation
7. Confusion matrix analysis
8. Feature importance analysis
9. Comparison of machine learning models

## Models

### Artificial Neural Network

A neural network is implemented using PyTorch to learn patterns associated with customer churn.

### Logistic Regression

Logistic Regression is used as a classical machine learning baseline for binary churn prediction.

### Random Forest

Random Forest is used as an ensemble model and to identify the features that contribute most to predictions.

## Evaluation Metrics

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
